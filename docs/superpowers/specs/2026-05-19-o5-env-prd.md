# O5 Env — 环境账号管理 PRD

> **文档版本**：1.1  
> **更新日期**：2026-05-19  
> **状态**：进行中（UI v1 已落地，v1.1 账号区优化待实现，API 未接）  
> **路由**：`/o5-env`  
> **所属产品**：mt-dev Dev Dash（`env.nextdev.cc`）

---

## 1. 背景与问题

内部开发、联调、验收时，需要在多套 O5 相关系统与环境之间切换测试账号。当前信息分散在各后台或表格中，查找成本高、复制账号效率低。

**O5 Env** 是 Dev Dash 下的子模块，提供「系统 → 环境 → 测试账号」三级浏览与快捷复制，作为 O5 系环境账号的统一入口（与「智邮 env」「aichat env」等并列，首期仅实现 O5）。

---

## 2. 目标

| 目标       | 说明                                                  |
| ---------- | ----------------------------------------------------- |
| 快速定位   | 按系统筛选环境，再查看该环境下的测试账号              |
| 高效复制   | 一键复制手机号，便于粘贴到登录框                      |
| 快速搜索   | 账号区内 Cmd+F 唤起搜索，支持中文、拼音、英文模糊匹配 |
| 常用直达   | 手动收藏账号置顶展示，减少重复查找                    |
| 可扩展布局 | 侧栏与列表区支持拖拽调宽/调高；账号区三列网格适应宽屏 |
| 独立滚动   | 环境列表、账号列表各自滚动，页面整体不滚动            |
| 可演进架构 | Mock 数据可替换为 API，不改动信息架构                 |

- 与真实 O5 后台的单点登录或自动登录
- 智邮 / AI Chat 环境模块（由其他 `DevDashModuleId` 承载，当前为 Coming Soon）

- 双击卡片复制、右键复制菜单、URL 搜索参数（`?q=`）、环境侧栏 `/` 快捷键搜索

## 5. 信息架构

```
App Rail（全局）
└── O5 env  (/o5-env)
    ├── 侧栏（可拖拽宽度）
    │   ├── 系统列表（上，可拖拽高度）
    │   └── 环境列表（下，独立滚动）
    └── 主区（可拖拽剩余宽度）
        ├── 环境标题 + 账号数量（固定）
        ├── 搜索栏（固定，Cmd+F 唤起）
        ├── 常用区（固定，有收藏时展示）
        └── 账号卡片网格（独立滚动，3 列响应式）
```

**级联选择规则**：

1. 选中**系统** → 环境列表过滤为该系统下环境；自动选中该系统下第一个环境（若有）。
2. 选中**环境** → 主区展示该环境名称与账号列表。
3. 未选环境 → 主区空态「请选择一个环境」。
4. 环境无账号 → 展示标题 +「该环境下暂无账号」。

## 7. 交互与视觉规范

### 7.1 布局与分栏

| 区域                 | 默认比例 | 约束      | 持久化 key       |
| -------------------- | -------- | --------- | ---------------- |
| 侧栏（相对主区）     | 22%      | 14% ~ 42% | `o5-env-main`    |
| 系统区（相对侧栏内） | 38%      | 22% ~ 62% | `o5-env-sidebar` |
| 主区                 | 剩余     | min 35%   | —                |

- 使用 `react-resizable-panels`（`Group` / `Panel` / `Separator`）。
- 分隔条：静态 `border` 色细线 + 小握把（竖向 `GripVertical` / 横向 `GripHorizontal`）。
- **按住/拖动分隔条时无额外高亮**（无黑色块、无 ring）。

### 7.2 选中态

- 系统/环境列表项：与 App Rail 一致，使用主题色 `primary` 背景（非硬编码蓝色）。
- 系统数量：`Badge`，选中时使用浅色变体。

### 7.3 滚动

- 页面级：`AppShell` 使用 `h-svh overflow-hidden`。
- 环境列表、账号网格区：`scrollbar-thin` 细滚动条。
- 环境标题、搜索栏、常用区固定在主区顶部不随 grid 滚动；仅账号网格区域 `overflow-y-auto`。

### 7.4 账号区布局（v1.1）

**顶栏结构**（自上而下，前两项始终固定）：

```
┌─────────────────────────────────────────────────┐
│ 行动中心 6173 · 42 个账号                        │
├─────────────────────────────────────────────────┤
│ 🔍 搜索账号…                    ⌘F   3 / 42     │
├─────────────────────────────────────────────────┤
│ 常用 (4)                                         │
│ [李权泓 · 天津美腾] [cs01 · 北京研发] …          │
├─────────────────────────────────────────────────┤
│ ┌──────┐ ┌──────┐ ┌──────┐                      │
│ │ 卡片 │ │ 卡片 │ │ 卡片 │                        │
│ └──────┘ └──────┘ └──────┘                      │
└─────────────────────────────────────────────────┘
```

**响应式列数**（随主区 Panel 宽度，非整页 viewport）：

| 主区宽度  | 列数 |
| --------- | ---- |
| ≥ 900px   | 3    |
| 600–899px | 2    |
| < 600px   | 1    |

- Grid gap：`gap-3`；卡片等宽填满，无 `max-w-2xl` 居中限制。
- 搜索有命中时，姓名/组织匹配片段高亮（`<mark>` 或等价样式）。

**单张卡片结构**：

```
┌─────────────────────────┐
│ 李权泓              ☆ 📋│  ← 姓名 + 收藏 + 复制（常驻）
│ 天津美腾科技有限公司     │  ← 组织 Badge
└─────────────────────────┘
```

- 手机号不在 UI 展示（含 hover 脱敏也不展示）。
- 收藏：空心星 / 实心星；`aria-pressed` 表示状态。
- 复制：ghost 按钮始终可见；成功后 1.5s「已复制」。

**常用区 chips**：

- 横向排列，可换行；每项显示「姓名 · 组织」。
- 点击 chip：复制该账号手机号（同 F-04）。
- chip 上可选小星标取消收藏。

## 8. 数据模型

### 8.1 前端类型（当前：`apps/web/src/mocks/o5-env.ts`）

```ts
type O5System = {
  id: string;
  name: string;
  count: number; // 展示用；建议 API 阶段由 environments.length 派生
};

type O5Environment = {
  id: string;
  systemId: string;
  name: string;
};

type O5Account = {
  id: string;
  envId: string;
  phone: string;
  name: string;
  org: string;
};
```

### 8.2 建议 API 契约（v1.2 草案）

| 方法 | 路径                                     | 说明         |
| ---- | ---------------------------------------- | ------------ |
| GET  | `/api/o5/systems`                        | 系统列表     |
| GET  | `/api/o5/systems/:systemId/environments` | 某系统下环境 |
| GET  | `/api/o5/environments/:envId/accounts`   | 某环境下账号 |

响应体与上述类型对齐；`count` 可由服务端计算或前端派生。

### 8.3 客户端持久化（v1.1）

| key                | 类型         | 说明                      |
| ------------------ | ------------ | ------------------------- |
| `o5-env-main`      | Panel layout | 侧栏↔主区分栏比例（已有） |
| `o5-env-sidebar`   | Panel layout | 系统↔环境分栏比例（已有） |
| `o5-env-favorites` | `string[]`   | 已收藏 accountId 列表     |
